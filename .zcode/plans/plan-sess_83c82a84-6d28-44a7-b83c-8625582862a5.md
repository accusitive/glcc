## Context

The SLP vectorizer (a12afe9) only rewrites straight-line code, so loops with runtime trip counts — the dominant array-processing shape (`for (i = 0; i < n; i++) dst[i] = src[i] + 1`) — still run fully scalar. This iteration adds a loop vectorizer: transform legal counted loops into a vector loop + scalar epilogue, with runtime alias checks when dis jointness can't be proven statically. Reductions (`sum += a[i]`) follow as a second phase once the core is green.

## Design

### Step 0 — Share the alias machinery (pure refactor)
Move `Object`, `opaque_offset`, `resolve`, and the `Access` overlap logic from `passes/slp/mod.rs` into a new `crates/glcc_mir/src/passes/alias.rs` (pub(crate)); slp switches to `super::alias::*`. No behavior change; slp tests must stay green.

### Step 1 — Loop shape + affine addresses (`passes/loopvec/`)
**Loop shape** (modeled on `LoopUnroll`'s `analyze` in `passes/unroll/mod.rs`, but symbolic): single latch, single exit, no `break`/`Invoke`/`Return`/`Switch` inside, only the header's `CondBr` branches. Header condition: `Icmp` on a header param (the induction variable) with the *bound on the rhs*:
- `Ult iv n`, init 0, step +1 → trip = `n` (unsigned).
- `Slt iv n`, init 0, step +1 → trip = `smax(n, 0)` (emit `select(n >s 0, n, 0)`).
- Constant bound, other steps/inits, `Ne`, reversed operands → bail (const-trip loops already get LoopUnroll+SLP).
Latch arg for iv must be `Add iv 1`; every other header param is deferred to Step 4 (reductions) or bails.

**Affine address scanner** (`loopvec/affine.rs`): resolve a load/store address to `{ root: Value, base_off: i64, iv_coeff: i64 }` by walking `GEP` (Const/Index steps, elem-size strides), `Add/Sub` with constants, `Mul/Shl` of the iv by a constant, and `bitcast`/`inttoptr`/`ptrtoint` passthrough (the C frontend emits inttoptr address arithmetic). Anything else → `None`.

### Step 2 — Legality
- Bail if any loop inst already touches a vector-typed value (idempotence), or any call/atomic/volatile in the loop, or `Icmp`/`Select`/`ExtractLane`-shaped non-elementwise uses of the iv outside address math.
- Allowed body: pure elementwise ops over (a) unit-stride affine loads, (b) loop-invariant values (splat), (c) constants (splat); plus unit-stride affine stores.
- **Dependence rules** per store/load pair on the same `Object`: coefficient mismatch → bail; constant element distance d > 0 or d == 0 → safe (elementwise); d < 0 → bail (loop-carried). Distinct `Known` objects → safe. Any `Opaque` involvement → Step 3's runtime check.

### Step 3 — Transform
CFG (reusing unroll's clone idiom: snapshot blocks, `push_block`, `clone_block_insts`-style cloning, retire originals with `Unreachable`, `remap_operands` for outside uses):
```
preheader: nn (smax for slt); vec_trip = nn >> log2(lanes); [alias check]
           CondBr(alias_ok, vec_header(0, splat inits), scalar_header(0, init args))
vec_header(vec_i, acc_vec…): vector body; vec_i += 1;
           CondBr(vec_i <u vec_trip, vec_header(…), vec_exit(…))
vec_exit:  start = vec_trip << log2(lanes); br scalar_header(start, init accs)
scalar_*:  clone of the original loop
```
Vector body: affine loads → vector `Load` (address = root + base_off + vec_i·lanes·es, rebuilt per iteration; LICM re-hoists invariants), ops 1:1 on vector types, stores → vector `Store`. Lanes = 128/elem_bits (same shapes as SLP). No alignment peeling (x86 unaligned loads are fine).

**Runtime alias check** (only when an Opaque pair exists): one `or`-chain of pairwise range disjointness tests — `(store_end ≤u load_base) | (load_end ≤u store_base)` with end = base + nn·es — branching to the scalar path when any fires.

### Step 4 — Reductions (after core is green)
A non-iv header param whose latch arg is `Add/Sub/FAdd/FSub(vload-affine, param)` (either order): vector accumulator param (splat init in preheader edge, `vOp` in body); in `vec_exit`, horizontal-reduce via `ExtractLane` + scalar ops and feed the result as the scalar header's entry arg on the vector path.

### Wiring
`LoopVec` as a `FunctionPass` transforming one loop per run (unroll's pattern); inserted in `function_pipeline` (`optimize/mod.rs`) **before** `LoopUnroll`, so const-trip loops still fall through to unroll+SLP.

## Verification
- Unit tests per step in `loopvec/tests.rs`: vectorize runtime-bound elementwise loop (assert CFG shape + vector ops + `verify_func`); negatives (backward dependence, stride ≠ 1, calls, iv misuse, already-vectorized idempotence); reduction case.
- JIT exec tests (`glcc_lower_cl/src/lower/tests.rs`, `native_has_simd` gate): n = 0, 3, 8 (epilogue/exact/empty), aliasing `dst = src + 1` (runtime check must route to scalar and stay correct), reduction sum.
- E2E: C file with runtime-bound loops through the driver at `-O2` — `--emit-mir` shows the vector loop; execute and compare against expected; disassembly shows packed `vmovups/vaddps`.
- Regression: full `cargo test -p glcc_mir -p glcc_lower_cl`, speedtest1 A/B against `a12afe9` (worktree, no stash). Small steps, `cargo build` after every edit; no `cargo fmt`.
